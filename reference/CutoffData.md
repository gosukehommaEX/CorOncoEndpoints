# Data observed at an analysis cutoff

Restricts data generated by
[`rOncoEndpoints`](https://gosukehommaEX.github.io/CorOncoEndpoints/reference/rOncoEndpoints.md)
to patients enrolled before an analysis cutoff (calendar time) and
censors PFS and OS at the cutoff. Response is counted as observed when
the patient responded and, if a time to response was generated, the
response occurred before the cutoff and before dropout.

## Usage

``` r
CutoffData(data, cutoff)
```

## Arguments

- data:

  A data frame returned by
  [`rOncoEndpoints`](https://gosukehommaEX.github.io/CorOncoEndpoints/reference/rOncoEndpoints.md).

- cutoff:

  Calendar time of the cutoff: a scalar, or one value per simulated
  trial in `data`, in increasing order of `sim` (as returned by
  [`EventTime`](https://gosukehommaEX.github.io/CorOncoEndpoints/reference/EventTime.md)).
  `NA` means no cutoff.

## Value

The rows of `data` with `accrual_time < cutoff`, with `pfs_tte`,
`pfs_event`, `os_tte`, `os_event`, `pfs_calendar_time` and
`os_calendar_time` recomputed, and the added columns `response_obs` and
`cutoff`.

## Examples

``` r
arm <- OncoArm(pfs.median = 6, orr = 0.3, resp.cor = 0.4, death.prop = 0.15,
               os.median = 15, resp.timing = "ttr", resp.tau = 1.5,
               ttr.median = 2.5)
dat <- rOncoEndpoints(nsim = 2, n = 100, arms = arm, a.time = c(0, 12),
                      seed = 1)
cut <- CutoffData(dat, cutoff = 9)
table(cut$sim, cut$response_obs)
#>    
#>      0  1
#>   1 60 13
#>   2 63 19
```
