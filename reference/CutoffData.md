# Data observed at an analysis cutoff

Restricts data generated by
[`rOncoEndpoints`](https://gosukehommaEX.github.io/CorOncoEndpoints/reference/rOncoEndpoints.md)
to patients enrolled before an analysis cutoff (calendar time) and
censors PFS and OS at the cutoff. A response counts as observed when the
patient responded and the response was determined before the cutoff,
before dropout and before the censoring of PFS.

## Usage

``` r
CutoffData(data, cutoff)
```

## Arguments

- data:

  A data frame returned by
  [`rOncoEndpoints`](https://gosukehommaEX.github.io/CorOncoEndpoints/reference/rOncoEndpoints.md).

- cutoff:

  Calendar time of the cutoff: a scalar, or one value per simulated
  trial in `data`, in increasing order of `sim` (as returned by
  [`EventTime`](https://gosukehommaEX.github.io/CorOncoEndpoints/reference/EventTime.md)).
  `NA` means no cutoff.

## Value

The rows of `data` with `accrual_time < cutoff`, with `pfs_tte`,
`pfs_event`, `os_tte`, `os_event`, `pfs_calendar_time` and
`os_calendar_time` recomputed, and the added columns `response_obs`,
`response_eval` and `cutoff`.

## Details

The time at which a response is determined is the time to response when
it was generated (`resp.timing = "ttr"` in
[`OncoArm`](https://gosukehommaEX.github.io/CorOncoEndpoints/reference/OncoArm.md)),
the landmark `resp.tau`, the time of the first tumor assessment, with
`resp.timing = "landmark"`, and the time of randomization with
`resp.timing = "none"`, so that the response of every enrolled patient
is then observed. Patients without an observed response have
`response_obs = 0`, as in an intention-to-treat analysis in which
patients without an assessment count as non-responders. `response_eval`
indicates whether the patient was followed up to the first tumor
assessment `resp.tau` (`NA` when `resp.tau` is 0), for analyses
restricted to patients with an assessment.

Data generated by version 0.2.0 of the package have no columns
`resp_tau` and `pfs_cens_time`; they are treated as having no landmark
and no censoring of PFS.

## Examples

``` r
arm <- OncoArm(pfs.median = 6, orr = 0.3, resp.cor = 0.4, death.prop = 0.15,
               os.median = 15, resp.timing = "ttr", resp.tau = 1.5,
               ttr.median = 2.5)
dat <- rOncoEndpoints(nsim = 2, n = 100, arms = arm, a.time = c(0, 12),
                      seed = 1)
cut <- CutoffData(dat, cutoff = 9)
table(cut$sim, cut$response_obs)
#>    
#>      0  1
#>   1 60 13
#>   2 63 19
```
